Scale Connection Test

Checks whether this tablet's browser can read a weight from a scale on the local network. Nothing is sent anywhere unless you tap the email button.

Step 1 – Check the scale directly

Enter the scale's address and number, then open the link. You should see text like {"gross":"2040",...}. If you do not, the problem is the network or the scale, not the browser.

Step 2 – Run the browser test

This page now tries to read the same weight itself, the way a web application would.
